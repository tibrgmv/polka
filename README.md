# Полка

Личная база того, что хочется прочитать, посмотреть и послушать, с заметками, цитатами и вопросами для размышления. Без сборки и без сервера.

## Что внутри

- `index.html` — всё приложение.
- `library.js` — готовая подборка (больше тысячи книг, фильмов, курсов, подкастов и альбомов) и 532 вопроса с заготовками ответов. Это обычный текстовый файл, его можно править.
- `sw.js`, `manifest.webmanifest`, иконки — чтобы приложение ставилось на экран телефона и работало без сети.

## Запуск на компьютере

    cd polka
    python3 -m http.server 8000

Откройте http://localhost:8000

## Хостинг

Подойдёт любой статический хостинг с HTTPS: GitHub Pages, Netlify, Cloudflare Pages. Загрузите содержимое папки как есть.

## На айфон

Откройте адрес сайта в Safari → «Поделиться» → «На экран Домой».

## Где лежат данные

В памяти браузера на том устройстве, где вы пишете. Синхронизации между телефоном и ноутбуком нет. Кнопки «Сохранить копию» и «Загрузить копию» внизу переносят полку, заметки, ответы и слова через JSON-файл; при загрузке побеждает более свежая версия записи.

Если очистить данные сайта в Safari или удалить иконку с экрана «Домой», записи пропадут. Делайте копию время от времени.

## Обновление

После правок в файлах поднимите номер версии в `sw.js` (`polka-v16` → `polka-v17`), иначе телефон будет показывать старую версию из кэша.

## Вставить раздел

Внизу полки есть кнопка «Вставить раздел». В неё вставляется текст такого вида, и всё из него добавляется на полку, в вопросы и в слова:

    {
      "items": [
        {"title": "Название", "author": "Автор", "type": "Книга",
         "tags": ["Химия"], "about": "О чём и зачем", "url": "",
         "parts": 0, "ideas": ["Главная мысль 1", "Главная мысль 2"]}
      ],
      "questions": [
        {"q": "Вопрос?", "tags": ["Химия"], "draft": "Заготовка ответа"}
      ],
      "words": [
        {"w": "слово", "m": "значение"}
      ]
    }

Типы: Книга, Видео, Подкаст, Статья, Фильм, Сериал, Музыка, Курс, Другое. Любое поле, кроме `title` у позиции и `q` у вопроса, можно пропустить. Повторная вставка того же текста ничего не дублирует.
